# MVP 

- what is an MVP? 

the simplest working version of a product that solves one core problem and allows a team to gather real user feedback with minimal effort.

 ## MVP — Phase 1
To prevent the project from becoming too large, I recommend building the following first:
Must Have
1. Student profiles
2. Demographic data
3. School/grade information
4. First-generation status
5. Program enrollment
6. Attendance
7. Mentorship matching
8. Mentoring session logs
9. College/career support tracking
10. Tasks/follow-ups
11. Notes
12. Postsecondary tracking
13. Alumni status
14. Basic dashboards
15. Data export
16. User permissions
17. Consent/privacy management
## Phase 2
1. Student outcomes surveys
2. Referral tracking
3. Student stories
4. Alumni engagement
5. QR attendance
6. Automated reminders
7. Advanced dashboards
8. Funder report generator
## Phase 3
1. Automated communications
2. Advanced analytics
3. Student/family portal
4. Mentor portal
5. Funder portal
6. Integration with other CAN systems
7. Predictive/early-warning analytics, if appropriate and ethically justified
